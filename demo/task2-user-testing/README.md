# Demo Task 2 - User Testing Templates cho Flow D1

Bộ file này là bản demo độc lập cho skill `task2-user-testing`, dùng để chuẩn bị phỏng vấn moderated user testing cho flow `D1 - Tạo support request` trên EMS.

## Phạm vi

- SUT: `https://prod-dev.ems-fitus.cloud`
- Flow: `D1 - Tạo support request`
- Kiểu test: moderated, think-aloud, đo task success, time on task, errors, hesitations và SUS
- Số participant mặc định: `5`

## File trong thư mục này

| File | Mục đích |
| --- | --- |
| `preparation_protocol.md` | Protocol chạy buổi test, objective, task script, metric, observer rules. |
| `participant_brief.md` | Script đưa participant đọc trước khi bắt đầu. |
| `participant_table.md` | Danh sách participant và metadata phiên test. |
| `session_notes_template.md` | Template ghi chú cho interviewer/observer. |
| `sus_score_sheet.md` | Phiếu SUS 10 câu và bảng tính điểm. |
| `usability_report_template.md` | Khung báo cáo tổng hợp sau khi chạy xong các session. |
| `session_notes/` | Thư mục để nhân bản note cho từng participant như `P01_session_notes.md`. |

## Cách dùng nhanh

1. Điền lịch test và participant vào `participant_table.md`.
2. In hoặc mở `participant_brief.md` cho participant đọc.
3. Dùng `session_notes_template.md` để nhân bản file note cho từng phiên.
4. Sau mỗi phiên, nhập điểm SUS vào `sus_score_sheet.md`.
5. Sau khi đủ dữ liệu, tổng hợp vào `usability_report_template.md`.
