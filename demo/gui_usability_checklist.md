# Task 1A - GUI Usability Checklist for Event Management System (EMS)

Checklist này được tự động thiết lập và kiểm duyệt thông qua Agent Skill `gui-usability-testing/step1-checklist` dựa trên việc đọc và phân tích toàn bộ tài liệu dự án trong thư mục `docs/` (bao gồm `docs/HW03_EMS_Intro_EN.md`, `docs/2026.HW03.GUI Usability EMS_En.md` và `docs/Kịch-bản-E2E-Test-Flow-Luồng-Admin.md`).

---

## 1. UI Inventory Từ Tài Liệu Docs

| Hạng mục (Category) | Thành phần UI & Tính năng đặc thù trích xuất từ `docs/` |
| --- | --- |
| **Màn hình (Screens)** | **User side:** Home page / Featured Carousel, Danh sách sự kiện, Trang chi tiết sự kiện, Form đăng ký tham gia (Student/Lecturer/Guest), Trang My Registrations + QR Ticket, Post-event star review, Form tạo Support Request (D1), Màn My Requests list & detail (D2).<br>**Admin side:** Dashboard tổng quan (4 thông số), Quản lý Events, Quản lý Users (Role, Block, Reset Password, Export Excel), Quản lý dữ liệu nền (Academic Contexts 3 cấp, Categories 80 icons, Campuses), Check-in tab (Real-time Barcode/QR scan, Accept/Decline pending review), Support Requests management (D3), Analytics (Recharts, DateRangeFilter, Campus breakdown), System Settings (Featured Event Carousel 7s, Social Media reorder, Footer RichText EN/VI). |
| **Vai trò (Roles)** | **Student**, **Lecturer**, **Guest** (User side) và **Admin** (Admin side). |
| **Luồng thao tác (Flows)** | Vòng đời sự kiện (Draft -> Published -> Important Update -> Check-in -> Reviews); Vòng đời support request (Tạo -> Pending -> Internal Note -> Resolved); Luồng đăng ký & nhận QR vé; Luồng reorder kéo-thả dữ liệu nền; Luồng chuyển đổi ngôn ngữ EN/VI. |
| **Bộ Widget (Widgets)** | Forms (Required field, Max Slots, Waitlist toggle, Additional Role, Validation error inline), Date/Time Picker (Cross-field validation), File Upload (Thumbnail 4:3, Banner 24:9, Support Request Attachment), RichTextEditor (Mô tả sự kiện, Footer settings), Icon Picker (~80 icons), Reorder Drag-and-drop (Opacity 50%), Search/Filter (Target Type, DateRangeFilter, Status tabs Pending/Resolved), Data Tables (Sort, Pagination, Export Excel), Cards & Carousel (Auto-play 7s), Lightbox Image Preview, Barcode/QR Scanner, Status Badges, Toast & Confirmation Modal. |
| **Trạng thái động (Dynamic States)** | Loading (Opacity 50% khi kéo thả), Disabled, Success, Failure (API error / validation error), Empty state, Pending Review, Stale data, Session expired. |
