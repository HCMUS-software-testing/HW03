## Kịch bản demo đề xuất

1. Mở thư mục skill và file `SKILL.md`.
2. Prompt Codex sử dụng skill trên một artifact nhỏ.
3. Hiển thị bảng/báo cáo do skill tạo ra.
4. Hiển thị bước sinh viên review và chỉnh sửa thủ công.
5. Chỉ ra artifact cuối được lưu ở đâu trong `submission/`.
