## 5. Checklist trước khi đóng ZIP

- [ ] Có Markdown và PDF cho báo cáo chính.
- [ ] Có checklist nhóm > 40 items và đủ IA-01...IA-04.
- [ ] Có kết quả checklist cho ít nhất 3 màn hình.
- [ ] Screenshot Failed items là ảnh thật từ EMS.
- [ ] Có 5 participant thật, liên hệ đã che phù hợp.
- [ ] Có metrics user testing và SUS/UEQ-S.
- [ ] Có screenshot cross-platform kèm EMS URL và email overlay.
- [ ] Mọi finding đã submit Google Form và có timestamp trong log.
- [ ] AI Audit Report ghi đủ tool/model/time/prompt/output.
- [ ] AI Critique dài 200-300 words.
- [ ] Có git commit log.
- [ ] Có Agent Skills và link demo nếu sử dụng.
