# Submission Rules

- Ngôn ngữ chính của bài nộp trong thư mục `submission/` là Tiếng Việt.
- Giữ nguyên tên file, route, account, mã lỗi, API endpoint, checklist ID, screenshot path và nhãn UI thực tế khi cần làm bằng chứng.
- Có thể giữ các thuật ngữ kỹ thuật phổ biến như `Pass`, `Fail`, `N/A`, `Bug`, `Usability`, `Expected`, `Actual`, `Severity` nếu đó là format bảng hoặc yêu cầu submission.
